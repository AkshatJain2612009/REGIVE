# ♻️ ReGive | Reduce Waste, Share Resources

ReGive is a community-driven platform designed to bridge the gap between surplus resources and those who need them most. By connecting individuals, businesses, and restaurants with verified NGOs, ReGive ensures that usable items—from surplus food to clothing and educational materials—do not go to waste.

## ✨ Key Features

- **📍 Interactive Resource Map**: A real-time map powered by Leaflet.js allowing users and NGOs to visualize available donations in their immediate vicinity (Defaulted to Mumbai, India).
- **📦 Instant Listing**: A streamlined donation form that allows users to pin their location and list items by category (Food, Clothing, Furniture, Books).
- **🤝 NGO Matching**: A "Claim" system that simulates the process of NGOs discovering and securing resources for distribution.
- **📈 Live Impact Tracking**: A dynamic statistics bar that tracks "Items Shared", "Lives Impacted", and "Waste Reduced" in real-time as users interact with the app.
- **🎨 Modern UI/UX**: Built with a professional "Glassmorphism" aesthetic using Tailwind CSS and the Plus Jakarta Sans typeface for a clean, high-end feel.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS (via CDN)
- **Interactivity**: Vanilla JavaScript (ES6+)
- **Mapping**: [Leaflet.js](https://leafletjs.com/) & OpenStreetMap
- **Icons**: [Font Awesome 6.0](https://fontawesome.com/)
- **Typography**: Plus Jakarta Sans (Google Fonts)

## 📖 How it Works

1. **Pin & List**: A donor lists an item and their location.
2. **NGO Match**: The item appears as a marker on the Resource Map.
3. **Collect & Distribute**: An NGO claims the item and arranges for pickup to deliver it to families in need.
